- `/vendor`: `drwxr-xr-x root root`.

### Descoberta importante
Embora `adb pull` seja bloqueado, o shell conseguiu ler bytes do APK de teste via `head`; os primeiros bytes exibiram a assinatura ZIP/APK `PK`. Isso indica que existe uma rota potencial de extração somente leitura pelo próprio shell (`exec-out`/stream), sem necessidade de alterar SELinux, rootear ou modificar o telefone. Essa rota deverá ser testada e validada byte a byte/hash antes de ser usada nos 13 overlays.

Os ativos oficiais exatos deverão ser obtidos de fontes legítimas/backup próprio quando a etapa Windows começar; o projeto não deve redistribuir material proprietário sem autorização.
