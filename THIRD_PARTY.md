# Third-party sources

This project will document and pin every upstream dependency used to reproduce the Razer Phone 1 MOD.

## Razer
- Razer Phone Developer Portal — factory images, flashing instructions, kernel and Wi-Fi source.
- Do not mirror proprietary factory/device software unless its license explicitly permits redistribution. Prefer official links + checksums.

## Android Platform Tools
- Use Google's official Android SDK Platform-Tools distribution. Record the exact version and SHA-256 used for releases.

## LineageOS
- `LineageOS/android_device_razer_cheryl` is an important upstream device-tree reference.
- Preserve upstream license notices for reused code.

## Evolution X / Android 17 base
The final base has not yet been selected. Add exact repository URLs, branches, commits and licenses here only after technical validation.

## Linux-AI OS
- Official project requested for integration: https://linux-ai-os.com/download.php
- Current downloadable desktop ISO identified during the project is AMD64; any ARM64 integration must document what is original, ported, emulated or independently recreated.
